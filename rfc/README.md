# NOWFLOCK RFC

[RFC-F0690-v3](NOWFLOCK_STANDARD.md) is the normative specification for the
NOWFLOCK version 3 wire protocol (`FNOW/3`, wire version `0x03`). The
[changelog](NOWFLOCK_CHANGELOG.md) records its revision history.

An implementation may describe itself as `FNOW/3 compatible` when it follows
the normative wire and behavior requirements. Modified protocols should use a
different version identifier instead of presenting incompatible behavior as
RFC-F0690-v3.
